# Tanvee Goenka: portfolio

A static HTML/CSS site built 1:1 from `Portfolio from Figma.fig`. It has no build step and no framework: open `index.html` or put the folder on any static host.

```
index.html                  Home page (hand-written, semantic HTML)
case-studies/
  indian-bank.html          Legacy to Loyalty      (generated from Figma)
  sthir.html                Sthir                  (generated from Figma)
  fermio.html               Fermio                 (generated from Figma)
assets/
  css/site.css              Tokens, header, footer, home page
  css/case-study.css        Shared rules for the case-study canvas and mobile layout
  css/pages/*.css           Per-case-study styles (generated)
  js/main.js                Hero text rotation, canvas/figure scaling, lazy videos
  img/  video/  icons/      Optimised assets exported from the Figma file
tools/figma-export/         Script that regenerates the case studies and assets
```

## Run it locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000. Opening `index.html` directly also works, but a local server matches how the site behaves once hosted.

## How the pages are built

**Home (`index.html`)** is written by hand with flexbox/grid, using the exact values from the Figma frame (fonts, sizes, colours, spacing). It includes the design's prototype behaviour:
- The hero line cycles through three phrases every 3 seconds.
- "View case study" buttons darken on hover.
- The nav links scroll to the case studies and "Why me?" sections. Resume opens the Google Drive link from the file.

It also reflows on tablets and phones. The Figma file only has the 1440px desktop design, so the small-screen layout is my adaptation.

**Case studies** are free-form Figma canvases with hundreds of absolutely placed layers, so they are exported by `tools/figma-export/build.js` instead of being hand-coded. The exporter:
- positions every layer exactly as in Figma
- lays text out line by line using Figma's own line breaks. Across the three pages, about 98% of text baselines land within 1.5px of the design.
- expands components, masks, tables, connectors and the two videos
- exports images as resized WebP files (the Figma file holds 282 MB of images; the site uses 5.3 MB)

`main.js` scales each 1440px canvas to the width of the browser window, so a case study looks the same at 1280px as at 1920px.

**Case studies on phones and tablets (1023px and below)** get a separate layout generated by `tools/figma-export/mobile.js`. The Figma file only has desktop frames, so this layout is my own design, built from the same layers:
- Text is re-set at mobile sizes and flows into a single column. Bullet lists become real lists.
- Photos and videos go full width. Captions stay under their picture.
- Cards keep their colours, corners and borders. Rows of chips wrap, and sets of cards, swatches or phone screens become 2- or 3-column grids.
- Diagrams (journey maps, mind maps, stakeholder maps, overlapping collages) keep their Figma layout. If they're still readable at the column width they're scaled to fit; if not, they become a strip you swipe sideways.
- Full-width coloured bands become the backgrounds of mobile sections, so each page keeps its colour rhythm.

When the automatic choice for a section is wrong, set a treatment for that layer in `MOBILE_OVERRIDES` at the top of `build.js` (`figure`, `scroll`, `scroll-center`, `flow`, `solo`, `descend` or `skip`), then re-run the exporter. Loose layers that belong together but aren't in a shared frame, like the Sthir form-experimentation collage, can be listed under `groups` and shown as one figure or as a row. The shared header and footer come from `tools/figma-export/partials.js` and are written into every page, including `index.html`.

## Editing

- **Home page:** edit `index.html` and `assets/css/site.css` directly.
- **Header/footer links (resume, email, LinkedIn):** edit `tools/figma-export/partials.js`, then re-run the exporter. It rewrites the marked header and footer regions in `index.html` too.
- **Case studies:** change the design in Figma, export the file again (File → Save local copy), replace `Portfolio from Figma.fig`, then run:

  ```bash
  cd tools/figma-export
  npm install
  node build.js
  ```

  The exporter needs Node 18+, ImageMagick (`magick`) and `ffmpeg`. On macOS: `brew install imagemagick ffmpeg`. Images and videos that already exist are skipped. Delete `assets/img` or `assets/video` to force a fresh export.

## Known differences from Figma

- **Image adjustments are not applied.** About 35 photos in the file use Figma's exposure, contrast or temperature sliders. The site shows the original photos.
- **Proprietary fonts are swapped.** The ad mock-ups inside the Fermio case study use Product Sans and SF Pro, which can't be served from the web. They fall back to similar fonts.
- **"Hover to view the personas"** (Indian Bank) was a prototype-only interaction and is shown in its default state.
- **The mobile and tablet case-study layouts** are generated, not taken from Figma, because the file has no mobile frames. Some dense diagrams scroll sideways on phones rather than shrinking to unreadable text.
